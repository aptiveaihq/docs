The **console** is where you work with AptiveAI Agents: you start
[tasks](/concepts/tasks), follow them, answer your agents and set everything
up. This page walks through it from the sidebar down, so you know where each
thing lives. Every section links to the page that explains it in full.

## The sidebar

The sidebar is the same on every page. From the top:

| Row | What it does |
|---|---|
| **New task** | The first page of the console, where work starts. See [Starting work with an agent](#starting-work-with-an-agent). |
| **Pinned agents** | Agents you have pinned get a row of their own, right under New task, marked with a pin. Clicking one starts a task with that agent. |
| **Agents** | The word opens the [Agents page](/concepts/agents#where-agents-appear); the arrow beside it expands every agent you can see, ending in **All agents**. |
| **Activity** | Opens the [Activity panel](#the-activity-panel) beside the page you are on, instead of going to a page. |
| **Inbox** | What your agents need you to see — see the [Inbox](/concepts/inbox). |
| **Work** | [A page of cards](#the-work-and-configure-pages) for tasks, schedules and the Inbox. |
| **Configure** | [A page of cards](#the-work-and-configure-pages) for agents, connectors, skills, your settings and the admin area. |

Every agent row, pinned or under **Agents**, has a **…** menu:

- **Start new task** — the same as clicking the row.
- **Configure** — opens the agent's builder. Only shown if you may edit the
  agent.
- **Pin** / **Unpin** — adds the agent to, or takes it off, the top of the
  sidebar. Pins are yours alone; see
  [Pinning and icons](/concepts/agents#pinning-and-icons).

**Work** stays highlighted while you are on a task or a schedule, and
**Configure** while you are on connectors, skills or Settings, so you can
always tell where you are.

<Aside type="note">
  AptiveAI's own staff see one more group at the bottom of the sidebar,
  **Master admin**. It holds the tools AptiveAI uses to run the service, and
  customers never see it.
</Aside>

## Starting work with an agent

Clicking an agent — in the sidebar, on New task or on the Agents page — opens
**New task** with that agent chosen. The breadcrumb reads
**New task / *the agent's name***, the page says *You're working with …* above
the agent's purpose, and the agent's [conversation
starters](/concepts/agents#conversation-starters) are ready to click. The
composer shows the agent as a chip, and whatever you send goes to it.

<ThemedImage
  dark={landingDark}

The address is `/?agent=<id>`, so the page can be bookmarked or shared with a
colleague who can see the same agent. Clicking a conversation starter sends its
message straight away; to write your own, type in the composer. Clear the chip
to get a plain answer with no agent instead. [Tasks](/concepts/tasks#starting-a-task)
covers what happens next.

## The Work and Configure pages

**Work** and **Configure** each open a page of cards, one card per place you
can go. Work holds what your agents do and when:
[Tasks](/concepts/tasks), [Schedules](/concepts/schedules) and the
[Inbox](/concepts/inbox).

Configure holds how your agents are set up and how the app works for you:
[Agents](/concepts/agents), [Connectors](/concepts/connectors),
[Skills](/concepts/skills), [Personal
sign-ins](/reference/settings/sign-ins),
[Notifications](/reference/settings/notifications),
[Settings](/reference/settings) and — for owners and admins —
[Admin](/administration/overview).

Each card has up to three links:

| Link | What it does |
|---|---|
| **Open** | Goes to the page. **Admin** opens in the portal at `aptiveai.io/admin`, which its card marks with an outside-link icon. |
| **Docs ↗** | Opens the page of this documentation that explains it. |
| **Ask** | Opens New task with a question already typed — *Explain Tasks: search the docs, summarise it, and link the pages.* Nothing is sent until you press Send, so you can change the question first. |

**Ask about Work** and **Ask about Configure**, in the page header, do the same
for the whole page: the question asks what you can do under that section. An
Ask task has no agent, so it answers from this documentation — no computer, and
no access to your systems.

## The Activity panel

**Activity** opens your tasks as a panel beside whatever page you are on, so
you can keep an eye on them without leaving it. While it is open, the sidebar
shrinks to its icons; close the panel and the sidebar comes back as it was.

<ThemedImage
  dark={activityDark}
  light={activityLight}
  url="console.aptiveai.io/work"

At the bottom, **Group by** switches how the panel is read: **None** (the
default, one list), **Agent** or **Status**. Grouped by **Agent**, every agent
you can start a task with has a group of its own, and its **+** opens New task
with that agent chosen. The **+** at the top of the panel opens New task with no
agent chosen. Tasks waiting on you come first. See [The Activity panel](/concepts/tasks#the-activity-panel)
for the rest.

## Where to find things

| Looking for | Where it is |
|---|---|
| A task you or a colleague started | **Activity**, or **Work → Tasks** |
| A schedule | **Work → Schedules** |
| A question waiting on you | **Inbox**, or the top of **Activity** |
| Every agent, or a new one | **Agents** in the sidebar, **All agents** at the end of its list, or **Configure → Agents** |
| Your own sign-ins to websites an agent opens | **Configure → Personal sign-ins** — the [Personal sign-ins](/reference/settings/sign-ins) section of Settings |
| Which notifications reach you, and how | **Configure → Notifications** — the [Notifications](/reference/settings/notifications) section of Settings |
| Your plan, AI credit, theme | **Configure → Settings** |
| Language and your account | The account menu, under your avatar in the top-right corner |
| Members, invitations and billing | **Configure → Admin**, for owners and admins — see [The admin area](/administration/overview) |

The **Agents page** lists every agent you can see, as tiles or a table, with
each one's state, last task and next scheduled task. **Start a task** opens New
task with that agent; **New agent** opens the builder.

## On a phone

On a phone the sidebar becomes a bar at the bottom of the screen: **Menu**,
**Work**, **New task** in the middle, **Agents** and **Activity**. **Menu**
opens the full sidebar as a side panel, with **Agents** expandable and the same
**…** menu on every agent row.
