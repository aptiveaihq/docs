The **Inbox** is everything an agent needed you for, in one place: a task
waiting on your answer, work that finished or failed, an automation that skipped,
a connector that stopped working. Answer a question from the Inbox and the
task carries on — you do not have to open it.

Notifications reach you in up to three places:

| Where | What you see |
|---|---|
| **In the app** | The bell in the header, with a count of unread notifications, and the **Inbox** page |
| **By email** | A message to your account's address, for the kinds you choose |
| **On this device** | A desktop notification while the AptiveAI Agents tab is in the background, if you turn it on |

You choose which kinds reach you where in
[Settings → Notifications](/reference/settings/notifications).

## The Inbox page

Open **Inbox** from the sidebar (or from the **Work** page). It lists
**All notifications**, newest first, with a filter box. **Mark all read**
clears the unread count; **Dismiss all** empties the list. Each notification
has its own **×** to dismiss it, and a button to act on it:

- **Answer** — for a task waiting on you: an answer box opens right there, and
  **Send answer** sends it to the task.
- **View task** — opens the task.
- **Open** — opens whatever the notification is about.

The bell in the header opens the same notifications as a panel, with
**Mark all read** and **Clear**, from any page.

<Aside type="tip">
  A task waiting on your answer also raises a card that follows you from page
  to page until you answer it, so a question is hard to miss even when you are
  working elsewhere in AptiveAI Agents.
</Aside>

## What you are told about

| Notification | Sent when | Sent to |
|---|---|---|
| **A task finishes** | A task completes | The person who started it |
| **A task fails** | A task fails | The person who started it |
| **A task is waiting on an answer** | An agent asks a question, or stops for an approval | The person who started it |
| **An agent sends you a message, or someone shares a task with you** | An agent messages you by name, or a task, automation or agent is shared with you | That person |
| **An automation skips a task** | An [automation's run is skipped](/concepts/automations#skipped-runs), except the quiet reasons | Everyone who can see the automation |
| **A connector needs reconnecting** | A [connector's](/concepts/connectors) credential stopped working | The workspace |
| **Someone asks for a change to an agent** | An agent asks to [change itself](/concepts/agents#how-an-agent-updates-itself) in a task started by someone who cannot approve it | The owners and admins who can approve it |
| **A change you asked for is approved or rejected** | That request is decided | The person who asked |
| **AI credit is running low** | The account's AI credit falls below its warning level | Owners and admins |
| **The trial is about to end** | The trial ends within seven days | Owners and admins |
| **A payment is overdue** | The latest invoice is unpaid | Owners and admins |

A change request arrives with **Approve** and **Reject** on the card itself.
An automation that keeps skipping for the same reason sends one notification,
not one per run, and account notifications are sent once per condition, so
a burst of activity does not flood you.

## By default

| | In the app | By email |
|---|:---:|:---:|
| **A task is waiting on an answer** | Always | Off |
| **An agent sends you a message, or someone shares a task with you** | On | On |
| **AI credit is running low**, **The trial is about to end**, **A payment is overdue** | On | On |
| Every other kind | On | Off |

**A task is waiting on an answer** is always shown in the app: a task that has
stopped to ask you something has no other way to say so. Everything else,
including that kind's email, is yours to switch.

Every email carries an unsubscribe link that turns the same setting off.
