A **task** is one piece of work: *"reconcile this week's supplier invoices"*,
*"find out why order 4471 has not shipped"*. You start it with a message, an
[agent](/concepts/agents) works on it — on a computer of its own, with the
[connectors](/concepts/connectors) it has been granted — and the task keeps
everything that happened: the conversation, every step the agent took, the
questions it asked, the files it wrote and what it cost.

A task can also be started by a [schedule](/concepts/schedules). Either way,
it lives at its own page, `/tasks/<id>`, and in the [Tasks list](#the-tasks-list).

## Starting a task

**New task**, the first row of the sidebar, is where work starts.

<Steps>

1. **Pick an agent.** Click one under **Your agents**, or type `@` or `/` in
   the composer and choose it. The page becomes *You're working with …*, with
   the agent's purpose and its conversation starters. A pinned agent in the
   sidebar opens this page directly.

2. **Say what you need.** Type your message, or click a conversation starter
   to send its message straight away. Type `/` to add a
   [skill](/concepts/skills). Attach files with **Attach a file** or by
   dropping them on the page — up to 20 files of 25 MB each; images can be
   marked up with **Annotate** first. See [Files](/concepts/files).

3. **Send.** The task starts and you land on its page.

</Steps>

Sending with **no agent** gets you a plain answer instead — no computer and no
access to your systems. That task is shown as **Answer directly**, and you can
still hand it to an agent later with **Choose an agent**.

<Aside type="note">
  An agent works on [one task at a time](/concepts/agents#one-task-at-a-time-per-agent).
  If it is already busy, the composer says so before you send, with a link to
  the task it is working on.
</Aside>

## The task page

### The transcript

The conversation, top to bottom: your messages and their attachments, the
agent's replies, and each step it took in plain words — *Opening …*,
*Clicking …*, *Titled the task: …*. Consecutive steps fold into one line such
as **12 steps**; open the fold to read them. A fold says on its closed line
when something **didn't work** or is still **working…**.

### Steering it

While the agent works, the composer stays open: *Steer this task, or @ another
agent to help…*. A message you send reaches the agent at its next step. Type
`@` to **Bring in an agent** to help; on a task with no agent, **Choose an
agent** hands the whole task to one.

To stop, use the button in the send slot — **Interrupt this task** pauses it
where it is (*Send another message to carry on*). From the keyboard, **Esc**
then **Enter** interrupts. **End task** in the header stops it for good and releases
its computer; anything it already did in your systems stays done.

A task that has completed, failed, been stopped or paused picks up again when
you send it another message.

### Questions and approvals

When the agent needs you, the task stops and a card takes the composer's place.

- **A question** — the agent asks something only you can answer, sometimes
  with choices. Answer it and the task carries on.
- **An approval** — the agent is about to do something that cannot be undone:
  send a message, submit a form, delete, spend money, or write to one of your
  systems. The card says exactly what, and you choose:

| Button | Effect |
|---|---|
| **Approve** | Run this action once, then carry on |
| **Approve all** | Run this and stop asking for the rest of this task |
| **Decline** | Skip this action and tell the agent why — there is a box for what to do instead |

A task waiting on you shows as **Needs you**, and reaches you in the
[Inbox](/concepts/inbox), where you can answer it without opening the task.

<Aside type="caution" title="Sending the agent a password or code">
  An agent types a password or one-time code only if **you sent it** in the
  conversation, and only after an approval card for that. Once typed, the value
  is removed from the task's history — the transcript shows it as hidden. An
  unanswered card for a code expires after an hour. Values shorter than six
  characters are not hidden. For accounts you use often, save a
  [personal sign-in](/reference/settings/sign-ins) instead.
</Aside>

## The live view

The **live view** is the agent's computer, live: its real screen, as the agent
clicks and types. It opens by itself in the side panel the first time the
agent uses the screen, and **Full screen** gives it the whole page.

You can use the computer yourself through it — type a one-time code, finish a
sign-in, show the agent where something is — and a composer over the screen
(**Show chat** / **Hide chat**) lets you talk to the agent while you watch.
**Show what the agent is doing** opens a commentary of its steps as it goes.

The live view is yours to open and close; the agent cannot open or close it.
When the agent tells you what its computer is doing, it has just checked
rather than assumed. After a task ends, its computer is kept for five minutes — so the
next task starts faster and the screen is still there — and then released.

## The side panel

Three tabs beside the transcript, which can sit to the right or below
(**Layout**), be resized or be collapsed:

- **Live view** — see above.
- **Details** — a **Summary** once there is one; the **Computers** the task
  used; the **Tools** it had, and any granted tools it could not use; and
  **Task details**: status, the instruction, the agent, duration, what it cost
  (such as *$0.004 AI · 3 min on a computer*) and, under **More details**, the
  model and when it started and finished.
- **Documents** — every file in the task: the ones attached to it, the ones a
  connector returned and the ones the agent made. See [Files](/concepts/files).

## Names

A task is named from its first message until, after its first reply, it gets
a short title of its own. An agent can also title a task when its instructions
say how. Click the title to rename it; a name a person types always wins, and
clearing it brings the automatic title back.

## Sharing and who sees a task

A task is yours until you share it. The chip in its header — **Only you**,
**You + 2** — shows who has access, and selecting it opens the share box.

- **People you add** can see the task and watch it, live view included. They
  cannot send messages, answer questions, approve or stop it: for them it is
  **read-only** ("You can view this task").
- **Continue in my own task** is how a person who can only view a task works on
  it. It starts a new task of theirs from that point, on their own computer and
  browser, and leaves the original untouched.
- **People who can see the schedule** that started a task see it too. Only
  people with **Can edit** on that schedule can answer and approve on its tasks.
- **Workspace owners** can open any task in their workspace by its link, to look
  — it is read-only for them, and it does not appear in their Tasks list.
- Only the person who started a task can rename it, share it or delete it.

**Copy link** gives a short `/s/…` address. The link only points the way: the
person who opens it still needs access, or to be an owner.

**Delete task** removes the task from every list, search and link straight
away. A deleted task can be recovered for 30 days: ask your workspace owner or
AptiveAI support. After that only its conversation can be recovered — see
[How long a task is kept](#how-long-a-task-is-kept). A task that is still
working cannot be deleted.

The rules are the same for tasks, schedules, agents and skills — see
[Sharing](/concepts/sharing).

## The Tasks list

**Tasks** (under **Work**) lists every task you can see: its **Task** name with
its summary or the question it is waiting on, the **Agent**, **Status**,
**Started** and **Duration**. Tasks waiting on you are gathered in a
**Needs you** band at the top, whatever the filters. Tasks started by the same
schedule fold into one row you can open.

Filter by **Status**, **When** (today, 7 days, 30 days) and **Agent**, or type
in the search box to match names, summaries, instructions and more. The list
refreshes by itself.

### Statuses

| Status | Meaning |
|---|---|
| **Running** | The agent is working on it |
| **Needs you** | Waiting on your answer or approval |
| **Paused** | The agent has replied, or was interrupted, and is waiting for your next message |
| **Completed** | Done |
| **Failed** | Something went wrong; the transcript says what |
| **Stopped** | Ended on purpose — by a person, or because an approval expired — with the reason recorded |

Older tasks may also show **Incomplete**, **Skipped** or **Expired**, statuses
that newer tasks record as **Stopped** with a reason.

### The Activity panel

**Activity** in the sidebar opens your tasks as a panel beside whatever page
you are on. **Group by** **Agent** gives every agent you can start a task with
a group of its own — with a **+** to start a new task with it — while **Status**
groups them by status, and **None** (the default) shows one list. Tasks waiting
on you come first. **Pin to the top** keeps a task at the head of the panel for
everyone in the workspace.

## How long a task is kept

Every task is kept on the same clock, counted from its last activity — or, once
it is deleted, from the moment it was deleted:

| What | Kept for |
|---|---|
| The conversation: your messages, the agent's questions and your answers, and the agent's replies | 1 year |
| The detail: each tool call, what came back, and system lines | 30 days |

When the year is up, the task itself is removed with its conversation. A task
that is still working or waiting on someone is never removed. Files have their
own, shorter limits — see [Files](/concepts/files).

## Paid access

Starting or restarting a task needs [paid access](/concepts/agents#paid-access).
Without it, AptiveAI Agents is not shown: everyone who opens it is sent to a page
that says why — for example *No AI credit is available* — with **Contact us**.
The admin area and your account page stay open, with the reason in a banner. A
task that was already working when the credit ran out finishes; it is never
stopped halfway because credit ran out. See
[Usage and credit](/administration/usage#paid-access).
