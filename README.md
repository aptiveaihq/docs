# AptiveAI Docs

Source for the AptiveAI documentation site: product guides, agent and integration references,
and onboarding material for teams adopting AI across their processes.

## Status

Scaffolding pending. The repository is intentionally empty apart from this README.

The site is planned to follow the same setup as the
[clustercode docs](https://github.com/clustercodehq/docs) (Astro + Starlight).

## Scope

- **Getting started** — connecting a first process and putting an agent on it
- **Agents** — browser and computer-use capabilities, what they can drive, and their limits
- **Integrations** — connecting internal systems, available MCP servers and clients
- **Operations** — deployment, access control, observability
